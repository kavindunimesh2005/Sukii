## 🌟 Key Features

- **2026 Centerstage 3D Hero**: Interactive 3D book cover with real-time cursor tilt, directional foil glint, and 4 dynamic studio lighting rig modes (*Studio Diffuse*, *Chiaroscuro Noir*, *24K Golden Hour*, *Holographic Cyan*).
- **Dual-Direction Kinetic Marquee**: High-velocity typographic ribbon with solid & wireframe stroke outlines and audio haptics.
- **Interactive 3D Book & Unfolded Jacket Studio**: 360° volumetric rotation, macro spine deboss inspector, and mechanical flat jacket unwrap with printer registration marks.
- **Live Metallic Foil Stamping Lab**: Real-time foil customizer rendering 24K Gold, Platinum Mirror, Rose Copper, and Blind Deboss on 3D cloth.
- **Cinematic 4K Craft Film Reel**: 2.39:1 Cinemascope showreel with live timecode HUD, audio equalizer visualizer, and chapter selector.
- **Exploded 3D Book Anatomy Dissection**: 5-layer 3D exploded view (French Flap Jacket, Scandinavian Millboard, Endpapers, Smyth-Sewn Book Block, Crash Mesh).
- **Swiss Typographic Caliper Lab**: Real-time tracking, leading, and golden ratio ($\Phi = 1.618$) calibration playground.
- **Virtual 3D Open Spread Inspector**: Interactive double-page spread with leather/cloth textures, zoom loupe, and colophon specifications.
- **Atelier Bento Ecosystem Matrix**: Substrate repository vault, live commission slate counter, and certified ISO-12647-2 print benchmarks.
- **Web Audio Synthesized Haptics**: Procedural audio feedback for paper rustling, metallic foil chimes, and tactile button clicks.
- **Editorial Archive & Filter Suite**: Complete collection showcase with format filtering and case study detail views.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `pnpm` / `yarn`

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/kavindunimesh2005/Sukii.git

# 2. Navigate to project directory
cd Sukii

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

### Production Build

```bash
npm run build
```
